# Regression with a Tabular California Housing Dataset

Predict `MedHouseVal` for the synthetic California Housing dataset in [Playground Season 3, Episode 1](https://www.kaggle.com/competitions/playground-series-s3e1). The metric is Root Mean Squared Error (RMSE), calculated on the untransformed target; lower is better.

## Data

The [official competition data](https://www.kaggle.com/competitions/playground-series-s3e1/data) contains 37,137 training rows and 24,759 test rows. It was generated by a deep learning model trained on the original California Housing dataset. The eight covariates are median income, house age, average rooms, average bedrooms, population, average occupancy, latitude and longitude. No original-dataset labels or other external data are added.

The training file has no missing values or identical full covariate vectors. However, 22,949 rows repeat an earlier latitude/longitude pair. The training target ranges from 0.14999 to 5.00001. All training rows are retained. IDs are used only for submission alignment.

Use `train.csv`, `test.csv` and `sample_submission.csv`; their SHA-256 hashes are recorded in [results/metrics.json](results/metrics.json). The data page identifies the data license as CC BY 4.0. Raw data is excluded from this repository and remains subject to the [competition rules](https://www.kaggle.com/competitions/playground-series-s3e1/rules).

Dataset citation: Walter Reade and Ashley Chow. *Regression with a Tabular California Housing Dataset.* Kaggle, 2023. https://www.kaggle.com/competitions/playground-series-s3e1.

## Method

1. Reserve 7,428 rows as an untouched random audit using seed 42. Divide the remaining 29,709 rows into 22,281 fitting rows and 7,428 selection rows using seed 43. This gives approximately 60/20/20 proportions.
2. Compare Ridge, CatBoost on the eight original covariates, CatBoost with fixed additional features and a 50/50 blend of the two CatBoost variants. Select the lowest selection RMSE before examining audit results or a new leaderboard score.
3. Refit the selected fixed recipe on the development rows and evaluate it once on the untouched audit. Then run a separate spatial diagnostic, holding out entire half-degree coordinate cells with `GroupShuffleSplit`, seed 44. Do not change features, parameters or weights after either evaluation.
4. Fit the selected recipe on all official training labels. Predict the test rows in the official template's ID order and verify unique IDs, columns, row count and finite positive values.

Ridge uses median imputation, standard scaling and `alpha=10`, all fitted on the relevant fitting partition. Each CatBoost model uses 1,200 trees, depth 6, learning rate 0.05, L2 regularization 6, seed 42 and two CPU threads. There is no early stopping or parameter search.

The engineered variant has 17 features: the eight originals, log1p transforms of income, rooms, bedrooms, population and occupancy, bedroom share, rooms per person, estimated households (`Population / AveOccup`) and nonbedroom rooms. These are fixed row-level calculations. Predictions from every model are bounded by the target range of its current fitting partition. The blend averages predictions on the original target scale.

## Measured local results

### Model selection

| Model | RMSE ↓ | MAE ↓ |
| --- | ---: | ---: |
| Fitting-mean baseline | 1.16090 | 0.91395 |
| Ridge | 0.72458 | 0.52454 |
| CatBoost, original features | 0.56503 | 0.39738 |
| CatBoost, engineered features | 0.56627 | 0.39903 |
| Equal CatBoost blend | **0.56452** | **0.39731** |

The blend was selected. Its advantage over the original-feature CatBoost is small and comes from one split; this does not establish a statistically significant improvement.

### Untouched random audit

| Model | RMSE ↓ | MAE ↓ |
| --- | ---: | ---: |
| Development-mean baseline | 1.16601 | 0.91762 |
| Selected blend | **0.58854** | **0.40850** |

The blend improves audit RMSE by about 49.5% over the mean baseline. Its signed mean error is -0.00927. The 397 audit targets at or above 5 are harder: RMSE is 1.13864, with mean underprediction of 0.83494. For the other 7,031 targets, RMSE is 0.54105. These label-defined groups are descriptive diagnostics, not model inputs.

Audit RMSE is 0.58962 for rows with coordinates seen in the development partition (5,692 rows) and 0.58502 for unseen coordinates (1,736 rows). These groups have different distributions; similar errors do not prove that location overlap has no effect.

### Spatial transfer diagnostic

The fixed half-degree grid split has 32,413 fitting rows in 143 cells and 4,724 validation rows in 36 disjoint cells. Selecting 20% of cells does not necessarily hold out 20% of rows.

| Model | RMSE ↓ | MAE ↓ |
| --- | ---: | ---: |
| Spatial fitting-mean baseline | 1.34324 | 1.11083 |
| Selected blend | **0.62629** | **0.43338** |

The higher error than the random audit suggests that transfer to withheld regions is harder in this split. It is not a controlled estimate of the effect of geography: fitting sizes and target distributions also differ. This diagnostic is run after selecting the recipe and does not influence submission weights or settings.

## Reproduction

From the repository root, create a Python 3.12 environment and install the pinned dependencies:

```sh
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Download the three official files after joining the competition and place them in `california-housing/data/`. Extracted files and their individual `.zip` archives are supported.

```sh
python california-housing/train.py --data-dir california-housing/data --output-dir california-housing/artifacts
python scripts/build_california_housing_notebook.py
```

The script saves `submission.csv` and `metrics.json` in the ignored output directory. The measured local run used Python 3.12.14, NumPy 2.3.5, pandas 2.2.3, scikit-learn 1.7.2 and CatBoost 1.2.8. Model comparisons, audit, spatial diagnostic and final fitting took about 21 seconds, excluding data download.

The [standalone notebook](solution.ipynb) contains the same code and runs on CPU with the official competition input attached. A different package/runtime environment can produce different predictions; submission records identify the exact prediction file by hash.

The [public Kaggle notebook](https://www.kaggle.com/code/mvfrsshiga/california-housing-catboost-spatial-validation), version 1, completed successfully on CPU in 107.3 seconds, including startup. It used Python 3.13.15, NumPy 2.1.3, pandas 2.3.3, scikit-learn 1.6.1 and CatBoost 1.2.10.

## Validation limitations

Random validation measures interpolation within the synthetic competition distribution and allows recurring coordinates across partitions. The selection score is optimistic for the chosen candidate. The random audit is a single independent split, not repeated cross-validation.

The spatial diagnostic measures a different task, has unequal cell sizes and includes regions adjacent to fitting cells. Its fitting partition can contain random-audit labels, so it is not an independent second audit. The final fit uses every official training label after evaluation. No tuning or prediction scaling follows the audit or official scores.

Synthetic targets are not current property valuations. Results do not establish performance on live real-estate transactions or causal effects of the features.
